# 제휴업체 포털 서버 연동 경계

현재 제휴업체 포털 화면은 UI 구조 검토를 위한 예시 화면이다. 로그인·초대·비밀번호 재설정·대시보드·쿠폰·제안·공지의 예시 데이터는 `app/partner/_portal/portal-data.ts`에만 존재하며 실운영 데이터가 아니다.

## 구현 전제

- 브라우저 저장소, URL, 클라이언트 쿠키로 역할이나 업체 소속을 결정하지 않는다.
- 서버는 HttpOnly, Secure, SameSite 쿠키의 세션으로 현재 주체를 판별한다.
- `/partner/*` 페이지와 해당 API마다 서버가 `partner` 역할과 정확히 하나의 업체 소속을 검증한다.
- 서버 인증 연동 전 화면의 수락·거절·로그인·등록·재설정 입력은 동작하지 않는다.

## 연결할 서버 계약

1. 현재 주체 조회: 업체 계정의 활성화 상태와 매장 식별자를 서버에서 반환한다.
2. 로그인: 아이디·비밀번호 인증 후 24시간 최대 수명의 HttpOnly 세션을 발급한다. 로그인 실패 10회면 1시간 잠금한다.
3. 초대 및 재설정: 운영자가 발급한 링크만 일회성으로 검증하며 발급 당일 KST 23:59:59에 만료한다. 비밀번호 재설정 시 해당 계정의 기존 세션을 전부 종료한다.
4. 제안 수락/거절: 대기 중인 해당 매장 제안인지 원자적으로 검증한다. 거절 사유 입력은 없다.
5. 대시보드 방문자 수: 매장 쿠폰의 실제 사용 완료 건만 KST 기준 오늘·이번 달·누적으로 집계한다.
